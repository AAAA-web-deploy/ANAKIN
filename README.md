# ANAKIN — Website v2

Static website built with HTML, CSS and JavaScript; no build system required.

## Launch locally
Open `index.html`, or run `python -m http.server 8000` from this folder and visit `http://localhost:8000`.

## Deploy on GitHub Pages
Create a public GitHub repository, upload the entire *contents* of this folder to the default branch, then choose **Settings > Pages > Deploy from a branch > main / root**.

## What's in version 2
- Chart section entirely removed.
- CA and all external token-related destinations show **COMING SOON**; no wallet or live trading functionality is enabled.
- Gallery expanded from 5 to 9 scenes with evenly spaced and responsive image cards and a 9-image modal.
- Existing assets preserved; four new `anakin_archive_*_v2.webp` story images added. These were cropped from a newly generated composite and are review-quality, not independently rendered original-sized artwork.
- Existing saga, FAQ, information tabs, arcade game, and Holocron helper preserved.
